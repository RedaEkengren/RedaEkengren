# Reda Ekengren

I build small, self-hostable software, mostly from Sweden and mostly in the open.

**CV:** [redaekengren.github.io/RedaEkengren](https://redaekengren.github.io/RedaEkengren/) (Swedish and English)

## Projects

| Project | What it is | Stack |
| --- | --- | --- |
| [FreeSMS](https://github.com/RedaEkengren/FreeSMS) | Shop management for independent auto repair shops that keeps working when the wifi does not reach under the car. [Demo site](https://redaekengren.github.io/FreeSMS/) | Go, HTMX, Postgres |
| [Hushroom](https://github.com/RedaEkengren/Hushroom) | End-to-end encrypted meeting rooms you reach with a link. No account, nothing stored, the server cannot read them. Live at [hushroom.io](https://hushroom.io) | TypeScript |
| [molnkartan](https://github.com/RedaEkengren/molnkartan) | How dependent Swedish municipalities and regions are on American cloud services, measured with open DNS signals. Live at [molnkartan.se](https://molnkartan.se/) | Python |

## Archived

- [Postly](https://github.com/RedaEkengren/Postly): a transactional email API that delivers its own mail from the EU through self-hosted KumoMTA instead of reselling Amazon SES. Never launched, kept public for the code.

## What I care about

- Software you can run yourself, under licenses that keep it that way (AGPL-3.0, Apache-2.0, MIT).
- Privacy by construction: store nothing you do not need, and prefer designs where the server cannot read the data.
- European infrastructure and fewer dependencies on things you cannot inspect.
